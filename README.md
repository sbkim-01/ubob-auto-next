# uBobs Auto Next

> 가톨릭대학교 **직무역량 포폴** 사이트(`catholic-edu.ubob.com`)에서 영상 학습 완료 후 나타나는 **다음 영상 확인 팝업의 `확인` 버튼을 자동으로 눌러주는 Windows용 도구**입니다.

영상이 끝날 때마다 표시되는 아래 유형의 팝업을 감지해 자동으로 `확인` 버튼을 클릭하고, 다음 영상으로 넘어간 뒤에도 계속 동작합니다.

## 기능

- 영상 학습 완료 팝업 자동 감지
- 해당 팝업의 `확인` 버튼 자동 클릭
- 다음 영상으로 이동한 뒤에도 계속 감시
- 자동 클릭 횟수 및 실행 로그 저장
- 마지막으로 학습한 페이지 주소 기억
- 별도 Chrome 프로필을 사용해 로그인 상태 유지
- 다른 일반 `확인` 버튼은 클릭하지 않도록 팝업 문구까지 확인

## 실행 환경

- Windows
- Google Chrome
- Node.js LTS

> Node.js 설치 시 `npm`이 함께 설치되어 있어야 합니다.

## 사용 방법

1. 이 저장소를 ZIP으로 다운로드하거나 Clone합니다.
2. 원하는 폴더에 압축을 풉니다.
3. `start.bat`을 더블클릭합니다.
4. 최초 실행 시 필요한 패키지가 자동으로 설치됩니다.
5. 자동으로 열린 Chrome 창에서 사이트에 로그인합니다.
6. 이후에는 해당 Chrome 창에서 평소처럼 강의를 재생하면 됩니다.

처음 한 번 로그인한 뒤에는 전용 Chrome 프로필에 로그인 상태가 유지되므로, 이후에는 보통 `start.bat`만 실행하면 됩니다.

## 동작 방식

영상이 끝나면 사이트에서 다음과 같은 학습 완료 팝업이 나타납니다.

```text
콘텐츠 학습

콘텐츠 학습이 완료되었습니다.
다음 콘텐츠 학습을 진행하시겠습니까?

[취소] [확인]
```

프로그램은 이 팝업을 감지한 경우에만 `확인` 버튼을 자동으로 클릭합니다.

단순히 화면의 모든 `확인` 버튼을 누르는 방식이 아니라, 팝업의 문구와 버튼을 함께 확인한 뒤 동작합니다.

## 종료 방법

다음 중 하나로 종료할 수 있습니다.

- 자동화용 Chrome 창 닫기
- 실행 중인 콘솔 창에서 `Ctrl + C`

## 실행 후 생성되는 파일

프로그램을 실행하면 아래 항목이 자동으로 생성될 수 있습니다.

```text
chrome-profile/   # 전용 Chrome 로그인 및 프로필 데이터
logs/             # 날짜별 실행 로그
state.json        # 자동 클릭 횟수 및 마지막 학습 페이지 정보
node_modules/     # Node.js 패키지
```

위 파일들은 `.gitignore`에 포함되어 GitHub에는 업로드되지 않습니다.

## 참고

- `start.bat`은 Windows `cmd.exe` 호환성을 위해 ASCII 및 CRLF 형식을 사용합니다.
- 사이트 구조가 크게 변경되면 자동 클릭 기능이 동작하지 않을 수 있습니다.
- 본 도구는 `catholic-edu.ubob.com`의 특정 학습 완료 팝업을 대상으로 합니다.
