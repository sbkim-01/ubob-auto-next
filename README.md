# ubob-auto-next

가톨릭대학교 **직무역량 포폴** 사이트(`catholic-edu.ubob.com`)에서 영상 학습 완료 후 나타나는 **다음 콘텐츠 확인 팝업의 `확인` 버튼을 자동으로 눌러주는 Windows용 도구**입니다.

> 영상 자체를 건너뛰거나 재생 시간을 조작하지 않습니다.  
> 영상이 정상적으로 끝난 뒤 사이트에서 표시하는 학습 완료 팝업만 감지해 처리합니다.

## 요구사항

- Windows
- Google Chrome
- Node.js LTS ([https://nodejs.org/ko/download](https://nodejs.org/ko/download))

Node.js 설치 시 `npm`이 함께 설치되어 있어야 합니다.

## 쉬운 시작

터미널 명령 없이 `start.bat` 파일로 실행합니다.

1. **Node.js 설치**  
   [https://nodejs.org/ko/download](https://nodejs.org/ko/download) 에서 LTS 버전을 받아 기본 옵션으로 설치합니다.

2. **프로젝트 다운로드**  
   GitHub 페이지 우상단의 **`<> Code`** → **Download ZIP** → 압축 해제

3. **`start.bat` 더블클릭**
   - 첫 실행 시 필요한 Node.js 패키지를 자동으로 설치합니다.
   - 최초 설치에는 인터넷 연결이 필요합니다.
   - 설치가 끝나면 자동화용 Chrome 창이 열립니다.

이후에는 아래 사용법대로 진행하면 됩니다.

## 사용법

### 1. 실행

압축을 푼 폴더에서 `start.bat`을 실행합니다.

실행되면 터미널 창과 함께 자동화 전용 Chrome 창이 열립니다.

### 2. 로그인

처음 실행한 경우 열린 Chrome 창에서 `catholic-edu.ubob.com`에 직접 로그인합니다.

로그인 정보는 프로그램이 사용하는 별도의 Chrome 프로필에 저장되므로, 일반적으로 한 번 로그인하면 다음 실행부터 다시 로그인할 필요가 없습니다.

> 세션이 만료된 경우에는 브라우저에서 다시 로그인하면 됩니다.

### 3. 강의 재생

평소처럼 **직무역량 포폴** 사이트에서 원하는 강의를 열고 영상을 재생합니다.

프로그램은 영상을 직접 제어하지 않고, 페이지에서 학습 완료 팝업이 나타나는지만 계속 감시합니다.

### 4. 다음 영상 자동 진행

영상이 끝나면 사이트에서 다음과 같은 유형의 팝업이 표시됩니다.

```text
콘텐츠 학습

콘텐츠 학습이 완료되었습니다.
다음 콘텐츠 학습을 진행하시겠습니까?

[취소] [확인]
```

이 팝업이 감지되면 프로그램이 `확인` 버튼을 자동으로 클릭합니다.

확인 후 사이트가 다음 콘텐츠로 이동하면 새 페이지에서도 계속 감시하므로, 다음 영상이 끝났을 때 같은 팝업이 나타나면 다시 자동으로 처리합니다.

단순히 화면에 있는 모든 `확인` 버튼을 누르는 방식이 아니라 아래 조건을 함께 확인합니다.

- 학습 완료 팝업인지 확인
- 팝업 문구 확인
- `확인` 버튼인지 확인
- 버튼이 실제로 화면에 표시된 상태인지 확인

## 실행 중 로그 예시

터미널과 로그 파일에서 대략 다음과 같은 기록을 확인할 수 있습니다.

```text
[2026-09-13 10:30:11] 자동 감시 시작
[2026-09-13 10:42:26] 콘텐츠 완료 팝업 확인 자동 클릭 (누적 1회)
[2026-09-13 10:57:03] 콘텐츠 완료 팝업 확인 자동 클릭 (누적 2회)
```

자동 클릭 횟수와 마지막 학습 페이지 정보도 함께 저장됩니다.

## 종료

다음 중 하나로 종료할 수 있습니다.

- 자동화용 Chrome 창 닫기
- 실행 중인 터미널 창에서 `Ctrl + C`

## 실행 후 생성되는 파일

프로그램을 실행하면 아래 파일 및 폴더가 자동으로 생성될 수 있습니다.

```text
chrome-profile/   # 전용 Chrome 로그인 및 프로필 데이터
logs/             # 날짜별 실행 로그
state.json        # 자동 클릭 횟수 및 마지막 학습 페이지 정보
node_modules/     # 실행에 필요한 Node.js 패키지
```

## 주의사항

- **`chrome-profile/`에는 로그인 쿠키, 세션 정보 등 계정과 관련된 데이터가 저장될 수 있습니다. 이 폴더를 다른 사람에게 공유하거나 GitHub에 업로드하지 마세요.**
- 프로그램을 다른 사람에게 공유할 때는 소스 파일만 공유하고, 본인 PC에서 생성된 `chrome-profile/`, `logs/`, `state.json`, `node_modules/`는 포함하지 않는 것을 권장합니다.
- 공용 PC에서 사용했다면 사용 후 `chrome-profile/` 폴더를 삭제하는 것이 안전합니다.
- 사이트의 화면 구조나 팝업 HTML이 변경되면 자동 클릭 기능이 동작하지 않을 수 있습니다.
- 이 도구는 `catholic-edu.ubob.com`의 특정 학습 완료 팝업을 대상으로 작성되었습니다.
- `start.bat`은 Windows `cmd.exe` 호환성을 위해 ASCII 및 CRLF 형식을 사용합니다.
